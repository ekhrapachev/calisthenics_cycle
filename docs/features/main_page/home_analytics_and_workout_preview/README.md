# Главная Forma: обновлённая аналитика и проверка состава перед стартом

Feature slug: `home_analytics_and_workout_preview`

Статус: **SPECIFIED · PROTOTYPED**

Дата: 2026-07-26

Пакет объединяет два связанных изменения пользовательского пути на главной:

1. вместо метрики серии показывается дата последней завершённой тренировки, а
   карточка общего числа тренировок получает прямой переход в историю;
2. выбор набора больше не запускает тренировку сразу — сначала пользователь
   видит состав и подтверждает старт.

## Проблема

Текущая карточка «Тренировок подряд» делает акцент на серии и личном рекорде,
хотя пользователю полезнее понимать, когда он тренировался в последний раз.
Переход к истории визуально недостаточно отделён от счётчика.

В текущем быстром запуске нажатие на набор сразу создаёт активную сессию.
Пользователь не успевает проверить упражнения и может начать не ту тренировку.

## Решение

- Карточка серии становится карточкой «Последняя тренировка» с абсолютной датой.
- Из неё удаляются «Личный рекорд» и декоративная иконка.
- В карточке «Всего тренировок» остаётся счётчик, а ниже появляется строка
  `История` с шевроном. Карточка целиком открывает историю.
- После выбора набора открывается полноэкранный экран «Состав тренировки».
- На экране показаны название, сложность, длительность и упражнения в точном
  порядке выполнения.
- Только кнопка `Начать тренировку` создаёт snapshot и активную сессию.
- Назад возвращает в bottom sheet выбора без создания сессии.

## Границы

В scope входит запуск с главной через `Начать тренировку → выбор набора`.
Просмотр уже активной тренировки и отказ без сохранения остаются в
[`discard_active_workout`](../discard_active_workout/README.md).

Редактирование состава, прогрессий и порядка упражнений на экране проверки не
предусмотрено.

## Приоритет требований

Этот пакет определяет целевое поведение следующей итерации и переопределяет:

- мгновенный старт и критерий `ровно два нажатия` из
  [`quick_start_workout`](../quick_start_workout/README.md);
- прежнюю композицию stat-card и запрет текста `История` из
  [`direct_home_navigation`](../direct_home_navigation/README.md).

Остальные требования связанных пакетов продолжают действовать.
