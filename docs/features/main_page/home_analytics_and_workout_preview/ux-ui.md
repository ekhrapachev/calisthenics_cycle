# UX/UI-изменения

## 1. Аналитика на главной

### «Всего тренировок»

Карточка сохраняет крупный числовой счётчик. Под счётчиком:

- подпись `Всего тренировок`;
- нижняя action-строка `История`;
- справа стандартный шеврон `›`.

Вся карточка — одна интерактивная область и ведёт на экран истории. Не делать
вложенную кнопку только вокруг текста `История`.

### «Последняя тренировка»

Карточка заменяет прежнюю `Тренировок подряд`.

Состав:

- заголовок `Последняя тренировка`;
- дата последней завершённой тренировки;
- без текста `Личный рекорд`;
- без иконки серии/огня.

### Единая типографика двух карточек

Счётчик `Всего тренировок` и дата `Последней тренировки` — равноправные
аналитические значения. Для них используется один typography token:

- одинаковый кегль: 36 px;
- одинаковая насыщенность: 850;
- одинаковая высота строки: 1;
- одинаковый верхний отступ и базовая линия;
- одинаковое межбуквенное уплотнение.

Дата не уменьшается относительно счётчика и остаётся в одну строку. Подписи
`Всего тренировок` и `Последняя тренировка` также используют один кегль,
насыщенность и цвет. Перенос второй подписи на две строки допустим и не меняет
размер текста.

Дата абсолютная и локализованная:

- текущий год: `24 июля`;
- другой год: `24 июля 2025`;
- время не показывается.

Абсолютный формат не устаревает в течение дня и однозначно отвечает на вопрос
«когда была последняя тренировка».

Если завершённых тренировок нет:

- значение `—`;
- подпись `Последняя тренировка`;
- пояснение `Ещё не было`.

Карточка не интерактивна. Переход в историю остаётся только у соседней карточки.

## 2. Выбор тренировки

Bottom sheet сохраняет текущий каркас, но меняет обещание:

- заголовок: `Выбери тренировку`;
- описание: `Выбери набор, чтобы проверить состав.`;
- справа на карточке — шеврон `›` вместо маркера мгновенного запуска.

Нажатие на карточку:

1. не создаёт сессию;
2. открывает экран проверки состава;
3. сохраняет позицию списка, чтобы возврат не сбрасывал контекст.

## 3. Экран «Состав тренировки»

Формат: отдельный полноэкранный уровень навигации, а не второй bottom sheet.
Так пользователь явно понимает, что перешёл от выбора к проверке.

### Верхняя панель

- кнопка назад с touch target 44 × 44 px;
- компактный заголовок `Состав тренировки`;
- без кнопки закрытия справа.

Системный Back и свайп назад повторяют кнопку назад.

### Заголовок и метаданные

- eyebrow `Перед началом`;
- название набора;
- сложность;
- `N упражнений`;
- ориентир `M мин`.

### Список упражнений

Каждая строка показывает:

- порядковый номер;
- пиктограмму;
- название;
- `подходы × цель единица`;
- выбранную прогрессию, если она отличается или уточняет выполнение.

Порядок и значения должны совпадать со snapshot, который будет создан после
подтверждения. Список только для чтения.

### Закреплённое действие

Внизу, над safe area:

> Начать тренировку

Во время запроса кнопка disabled и показывает `Начинаем…`.
Только успешный ответ открывает первое упражнение.

## 4. Возврат

Кнопка назад:

- возвращает в тот же bottom sheet выбора;
- сохраняет прокрутку списка;
- не создаёт активную тренировку;
- не записывает событие успешного старта.

Закрытие sheet после возврата ведёт на главную.

## 5. Адаптивность и доступность

- Поддержать ширины 320–430 px без горизонтального скролла.
- Длинное название набора — до двух строк.
- Длинное название упражнения — до двух строк, метаданные остаются видимыми.
- Список прокручивается независимо от закреплённой CTA.
- Все интерактивные области не меньше 44 × 44 px.
- После открытия экрана фокус переходит на заголовок.
- После возврата фокус возвращается на выбранную карточку.
- Шеврон не является единственным сигналом: карточка имеет доступное имя
  `Проверить состав тренировки <название>`.
