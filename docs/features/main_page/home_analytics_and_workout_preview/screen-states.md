# Состояния экранов

## Аналитика главной

| ID | Условие | Всего тренировок | Последняя тренировка |
|---|---|---|---|
| A-01 | Есть история в текущем году | число + `История ›` | `24 июля` |
| A-02 | Последняя тренировка в другом году | число + `История ›` | `24 июля 2025` |
| A-03 | История пуста | `0` + `История ›` | `—` + `Ещё не было` |
| A-04 | Загрузка | skeleton, без ложного `0` | skeleton |
| A-05 | Ошибка | retry для общего блока | не показывать устаревшую дату как актуальную |

## Picker

| ID | Условие | Поведение |
|---|---|---|
| P-01 | Наборы есть | карточки со шевроном, нажатие открывает preview |
| P-02 | Наборов нет | существующее пустое состояние и создание набора |
| P-03 | Длинный список | внутренний scroll, позиция сохраняется при возврате |
| P-04 | Набор удалён | карточка исчезает после синхронизации |
| P-05 | Ошибка загрузки | ошибка и `Повторить`, старта нет |

## Preview

| ID | Условие | Поведение |
|---|---|---|
| V-01 | Данные готовы | полный состав и активная CTA |
| V-02 | Загрузка | skeleton списка, CTA disabled |
| V-03 | Ошибка | сообщение, `Повторить`, назад доступен |
| V-04 | Пустой набор | пояснение, CTA disabled |
| V-05 | Длинный список | список scroll, CTA закреплена |
| V-06 | Старт выполняется | `Начинаем…`, повторные действия disabled |
| V-07 | Ошибка старта | inline-error, CTA снова доступна |
| V-08 | Устаревшая версия | обновлённый состав и просьба проверить повторно |
| V-09 | Уже есть active | переход к существующей сессии, новая не создаётся |
