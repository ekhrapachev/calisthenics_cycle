# QA и критерии приёмки

## Аналитика

- [ ] Общее число равно количеству completed-сессий.
- [ ] Discarded и active не увеличивают счётчик.
- [ ] Последняя дата выбирается по максимальному `completedAt`.
- [ ] Для текущего года показаны день и месяц, для другого — также год.
- [ ] Счётчик и дата имеют одинаковые кегль, насыщенность и высоту строки.
- [ ] Дата визуально не выглядит меньше счётчика на ширинах 320–430 px.
- [ ] Подписи обеих карточек используют одинаковый текстовый стиль.
- [ ] При пустой истории показаны `0`, `—` и `Ещё не было`.
- [ ] Нет текста `Тренировок подряд`, `Личный рекорд` и иконки серии.
- [ ] Карточка `Всего тренировок` целиком открывает историю.
- [ ] Карточка `Последняя тренировка` не выглядит интерактивной.

## Основной сценарий

- [ ] `Начать тренировку` открывает picker.
- [ ] Карточка набора открывает preview и не вызывает стартовый API.
- [ ] Preview показывает выбранный набор, а не соседний или предыдущий.
- [ ] Порядок, подходы, цель, единицы и прогрессии совпадают со snapshot.
- [ ] CTA создаёт одну активную сессию и открывает упражнение 1, подход 1.

## Возврат

- [ ] Кнопка назад возвращает в открытый picker.
- [ ] Системный Back и swipe-back дают тот же результат.
- [ ] Позиция списка и фокус на карточке восстановлены.
- [ ] После возврата нет session, snapshot и sets.
- [ ] Picker можно закрыть и вернуться на главную.

## Ошибки и конкуренция

- [ ] Ошибка preview не блокирует возврат.
- [ ] Ошибка старта оставляет пользователя на preview.
- [ ] Double tap не создаёт дубль.
- [ ] Изменённый набор обновляется и требует повторного подтверждения.
- [ ] Удалённый набор не запускается.
- [ ] Параллельно появившаяся active-сессия не дублируется.

## UI и доступность

- [ ] Проверены ширины 320, 375, 390 и 430 px.
- [ ] Длинные названия не перекрывают метаданные и CTA.
- [ ] Последняя строка видна над закреплённой CTA.
- [ ] Touch targets не меньше 44 × 44 px.
- [ ] Tab order логичен, focus видим.
- [ ] Screen reader получает заголовок, summary и доступные имена действий.
- [ ] Reduced motion не влияет на доступность состояний.
