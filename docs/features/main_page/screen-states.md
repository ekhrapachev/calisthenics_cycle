# Состояния экранов

## 1. Матрица главной

| ID | Данные | Активная сессия | CTA | Контент над CTA | Действие |
|---|---|---:|---|---|---|
| H-01 | Загружаются | Неизвестно | «Начать тренировку», disabled | Skeleton/зарезервированное место | Нет |
| H-02 | Загружены | Нет | «Начать тренировку» | Нет | Открыть выбор |
| H-03 | Загружены | Есть | «Продолжить тренировку» | «Сейчас выполняется» + сохранённое название | Восстановить сессию |
| H-04 | Ошибка | Неизвестно | «Начать тренировку», disabled | Сообщение и «Повторить» | Повторить загрузку |
| H-05 | Запуск | Нет | «Начать тренировку», loading/disabled | Нет | Защита от повтора |
| H-06 | Продолжение | Есть | «Продолжить тренировку», loading/disabled | Название активно | Защита от повтора |

На H-02 отсутствие наборов не меняет главную. Оно определяется после открытия
панели.

## 2. Матрица панели выбора

| ID | Условие | Содержимое | Основное поведение |
|---|---|---|---|
| P-01 | Есть наборы | Все карточки + «Управлять наборами» | Нажатие карточки запускает |
| P-02 | Наборов нет | Текст пустого состояния + «Создать тренировку» | Переход к списку наборов |
| P-03 | Идёт запуск | Выбранная карточка показывает progress, остальные недоступны | Ожидание результата |
| P-04 | Ошибка запуска | Сообщение у панели/карточки | Повторный запуск |
| P-05 | Список устарел | Недоступный набор удаляется после ответа 404 | Обновление списка |

## 3. Активная тренировка

Источник отображаемого названия — снимок активной сессии, а не текущая запись
набора. Поэтому состояние корректно, даже если набор:

- переименован;
- изменён;
- удалён.

Если имя в снимке по ошибке отсутствует, fallback: «Активная тренировка».

## 4. Восстановление позиции

Позиция определяется по снимку и сохранённым подходам:

1. пройти упражнения снимка по порядку;
2. внутри каждого пройти номера от 1 до `sets`;
3. найти первую пару без сохранённого результата;
4. открыть её;
5. если сохранены все пары, завершить сессию или открыть безопасное состояние
   завершения — не возвращать пользователя к первому подходу.

### Отдых

Минимально допустимое поведение этой итерации: после перезагрузки открыть первый
незавершённый подход без восстановления таймера отдыха.

Если приложение восстанавливает отдых, остаток считается от `completed_at`
последнего подхода и исходной длительности 120 секунд.

## 5. Навигация назад

| Откуда | Куда | Состояние |
|---|---|---|
| Панель выбора | Главная | Ничего не запущено |
| Упражнение, старт с главной | Главная | Сессия активна |
| Упражнение, старт из деталей | Детали набора | Сессия активна |
| «Мои тренировки» из панели/меню | Главная | Без изменений |
| Результат | Главная | Активной сессии нет |

## 6. Конкурентные события

- Двойное нажатие по карточке не создаёт две сессии.
- Если между загрузкой главной и нажатием появилась активная сессия на другом
  устройстве, сервер возвращает её; интерфейс переключается в продолжение.
- Если активная сессия завершилась на другом устройстве, повторная загрузка
  переводит главную в состояние начала.
- Если выбранный набор удалён на другом устройстве, показывается ошибка и список
  обновляется.
