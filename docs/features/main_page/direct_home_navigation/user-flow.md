# Пользовательские сценарии и flow

## 1. История тренировок

**Как пользователь**, я хочу нажать на счётчик тренировок на главной и одним
действием открыть историю, чтобы увидеть детализацию проведённых тренировок.

```text
Главная
  → карточка «12 / Всего тренировок»
  → История
  → Назад
  → Главная
```

Успех: история открыта одним нажатием; возврат сохраняет контекст главной.

## 2. Конструктор тренировок

**Как пользователь**, я хочу одним нажатием перейти в «Конструктор тренировок»,
чтобы создавать, редактировать и удалять тренировки.

```text
Главная
  → плашка «Конструктор тренировок»
  → Конструктор тренировок
      ├─ Новая тренировка → Редактор
      └─ Карточка тренировки → Детали
                                  ├─ Редактировать
                                  └─ Удалить → Подтверждение
```

Успех: раздел открыт одним нажатием; управление тренировками остаётся внутри
раздела.

## 3. Профиль

**Как пользователь**, я хочу нажать на иконку профиля в правом верхнем углу и
сразу открыть карточку профиля, чтобы быстро просмотреть или изменить данные.

```text
Главная → иконка профиля → Профиль → Назад → Главная
```

Успех: нет промежуточного меню; положение иконки на главной постоянно.

## 4. Пустая история

**Как новый пользователь**, я хочу открыть историю даже при нулевом счётчике,
чтобы понять, какие данные появятся после первой тренировки.

## 5. Пустой конструктор

**Как новый пользователь**, я хочу увидеть приглашение создать первую
тренировку, если список пуст.

## 6. Возврат

**Как пользователь**, я хочу возвращаться на главную в прежнее состояние, чтобы
не терять позицию и контекст активной тренировки.

## 7. Ошибка части данных

**Как пользователь**, я хочу пользоваться доступными переходами, даже если
статистика или другой блок временно не загрузился.
