# QA-чеклист

## Основные переходы

- [ ] Карточка количества тренировок открывает историю одним нажатием.
- [ ] Число, подпись, свободное место и шеврон дают одинаковый результат.
- [ ] Плашка конструктора открывает конструктор одним нажатием.
- [ ] Плашка конструктора является последним блоком перед закреплённой кнопкой
  запуска.
- [ ] Иконка пользователя открывает профиль одним нажатием.
- [ ] На главной нет кнопки с тремя точками и выпадающего меню.

## Тексты

- [ ] Используется «Конструктор тренировок».
- [ ] Нет опечатки «Конкструктор».
- [ ] В пользовательской навигации нет «Мои тренировки».
- [ ] В карточке статистики нет текста «История →».
- [ ] Шеврон истории центрирован по вертикали у правого края.
- [ ] Шевроны истории, конструктора и карточек тренировок одинаковы по символу,
  размеру, весу и цвету.

## Возврат

- [ ] Back из каждого раздела возвращает на главную.
- [ ] Сохраняется состояние активной тренировки.
- [ ] Не создаются дубли экранов при быстрых повторных нажатиях.

## Состояния

- [ ] `0` тренировок остаётся кликабельным.
- [ ] Проверены loading/error статистики.
- [ ] Проверен пустой конструктор.
- [ ] Проверен неавторизованный профиль.

## Доступность

- [ ] Все элементы достижимы Tab.
- [ ] Enter и Space активируют переходы.
- [ ] Focus видим.
- [ ] Доступные имена соответствуют `requirements.md`.
- [ ] Нет вложенных кнопок и ссылок.
- [ ] Touch target не меньше 44 × 44 px.

## Регрессия

- [ ] Быстрый запуск работает.
- [ ] Продолжение активной тренировки работает.
- [ ] Picker и управление тренировками работают.
- [ ] Создание, редактирование и удаление работают.
- [ ] Мобильная ширина 320–430 px не создаёт горизонтальный скролл.
