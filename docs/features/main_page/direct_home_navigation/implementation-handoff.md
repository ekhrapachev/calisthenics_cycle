# Handoff для реализации

## Затрагиваемые части приложения

- home topbar;
- карточка общей статистики;
- новый home navigation card;
- экран `routines` и его пользовательские тексты;
- обработчики переходов и доступные имена;
- аналитика главной.

## Рекомендуемая последовательность

1. Удалить состояние и разметку overflow-меню.
2. Заменить кнопку меню на прямую кнопку профиля.
3. Преобразовать первую статистическую карточку в одну кнопку.
4. Добавить плашку конструктора последним блоком после прогресса, перед
   закреплённой зоной запуска.
5. Применить единый визуальный токен шеврона и центрировать шеврон истории
   справа.
6. Переименовать пользовательские тексты экрана `routines`.
7. Добавить аналитику и доступные имена.
8. Проверить регрессию быстрого запуска и активной тренировки.

## Состояние и маршрутизация

В текущем прототипе достаточно существующих экранов:

- `history`;
- `routines` — внутреннее имя можно сохранить, пользовательское название
  меняется на «Конструктор тренировок»;
- `profile`.

Состояние `homeMenuOpen`/`menu` после реализации не требуется.

## Важная зависимость

`quick_start_workout/requirements.md` MP-07 содержит старое требование про пункт
«Мои тренировки» в меню. Для актуальной реализации этот пакет имеет приоритет:
вход в управление тренировками находится на главной отдельной плашкой.
