# Аналитика

## События

| Событие | Момент | Параметры |
|---|---|---|
| `home_history_opened` | Нажатие на карточку количества тренировок | `workout_count` |
| `home_workout_builder_opened` | Нажатие на плашку конструктора | нет |
| `home_profile_opened` | Нажатие на иконку профиля | нет |
| `home_navigation_returned` | Возврат в главную из одного из разделов | `source` |

`source`: `history`, `workout_builder` или `profile`.

## Ограничения

- Не передавать email, имя, названия тренировок и другие персональные данные.
- Не отправлять отдельное событие для нажатия на шеврон: это часть той же
  интерактивной области.
- Удалённое меню больше не должно генерировать menu-open/menu-item события.

## Метрики

- доля открытий истории с главной;
- доля открытий конструктора с главной;
- доля открытий профиля с главной;
- переход из конструктора к созданию/редактированию;
- снижение числа действий до целевого экрана с двух до одного.
