# Состояния экранов

## Главная

| Состояние | Карточка истории | Конструктор | Профиль |
|---|---|---|---|
| Данные загружены | Число и переход активны | Активен | Активен |
| История пуста | `0`, переход активен | Активен | Активен |
| Статистика загружается | Скелетон без ложного `0`; переход можно временно отключить | Активен | Активен |
| Ошибка статистики | Текст ошибки и «Повторить» внутри карточки | Активен | Активен |
| Активная тренировка | Без изменений | Активен | Активен |

## Состояния взаимодействия

Для карточки истории, плашки конструктора и иконки профиля:

- default;
- hover для устройств с указателем;
- pressed;
- focus-visible;
- disabled только при реальной невозможности перехода.

## История

- **С данными:** тренировки в обратном хронологическом порядке.
- **Пусто:** «Завершённые тренировки появятся здесь».
- **Загрузка:** скелетоны строк.
- **Ошибка:** сообщение и «Повторить».

## Конструктор

- **С данными:** список тренировок и «Новая тренировка».
- **Пусто:** «Здесь появятся ваши тренировки» и «Создать тренировку».
- **После удаления последней:** пустое состояние без возврата на главную.
- **Ошибка:** сообщение и повтор загрузки; создание доступно, если это безопасно.

## Профиль

- **С данными:** карточка пользователя.
- **Загрузка:** скелетон карточки.
- **Ошибка:** сообщение и повтор.
- **Неавторизован:** переход в существующий auth-flow.

## Возврат и повторные нажатия

- Повторное быстрое нажатие не создаёт дублирующиеся экраны.
- Back возвращает на тот же экземпляр главной.
- Если был открыт picker быстрого запуска, переходы главной недоступны до его
  закрытия согласно modal focus trap.
