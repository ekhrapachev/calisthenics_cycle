# Прямые переходы с главной

> Следующая итерация аналитических карточек описана в
> [home_analytics_and_workout_preview](../home_analytics_and_workout_preview/README.md)
> и имеет приоритет для карточек `Всего тренировок` и `Последняя тренировка`.

Feature slug: `direct_home_navigation`

Статус: **SPECIFIED · PROTOTYPED / реализация не начата**

Фича убирает промежуточное меню главной и делает три пользовательских раздела
доступными за одно нажатие:

1. история — через карточку количества тренировок;
2. конструктор — через отдельную плашку на главной;
3. профиль — через постоянную иконку справа сверху.

## Решение в одном абзаце

Кнопка с тремя точками и выпадающее меню удаляются. Вся карточка «Всего
тренировок» ведёт в историю и получает центрированный справа шеврон. Последним
блоком прокручиваемой главной, непосредственно перед закреплённой кнопкой
запуска, становится компактная плашка «Конструктор тренировок». В правой части
заголовка находится иконка профиля, которая сразу открывает профиль. Экран «Мои тренировки»
переименовывается в «Конструктор тренировок»; создание, редактирование и удаление
тренировок остаются внутри него.

## Границы фичи

Фича меняет навигацию и название раздела, но не меняет:

- быстрый запуск и продолжение тренировки;
- данные статистики, цикла и прогресса;
- модель тренировочных наборов;
- создание, редактирование и удаление внутри конструктора;
- состав карточки профиля и детализацию истории.

## Связанные фичи

- [quick_start_workout](../quick_start_workout/README.md) — закреплённое основное
  действие на главной сохраняется.
- [discard_active_workout](../discard_active_workout/README.md) — карточка
  активной тренировки и отказ без сохранения сохраняются.

Этот пакет заменяет пункт MP-07 `quick_start_workout` в части входа в управление
наборами: пункта в меню больше нет, вместо него используется плашка
«Конструктор тренировок».
