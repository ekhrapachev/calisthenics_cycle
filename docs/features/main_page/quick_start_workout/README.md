# Главная Forma: быстрый запуск тренировки

Feature slug: `quick_start_workout`

Статус: **IMPLEMENTED локально / публикация не подтверждена**

Эта папка — самостоятельный feature-пакет для изменения главной страницы Forma.
Материалов достаточно, чтобы без дополнительного контекста:

1. проверить текущее поведение;
2. открыть целевой кликабельный прототип;
3. обновить продуктовые требования;
4. реализовать изменение в приложении и API;
5. проверить все состояния и переходы.

## Решение в одном абзаце

Блок «Мои тренировки» полностью исчезает с главной. Внизу главной всегда
закреплено одно основное действие с двумя продуктовыми состояниями:
«Начать тренировку» или «Продолжить тренировку». Новый запуск занимает два
нажатия: основная кнопка открывает выбор набора, нажатие на набор сразу запускает
тренировку. При активной сессии над кнопкой показывается активный набор, а
«Продолжить тренировку» одним нажатием возвращает к первому незавершённому
подходу.

## Как пользоваться прототипами

Оба HTML-файла автономны и открываются напрямую в браузере.

В целевом прототипе карта слева позволяет отдельно открыть:

- главную без активной тренировки;
- панель выбора набора;
- главную с активной тренировкой;
- остальные существующие экраны приложения.

На мобильной ширине карта скрыта. Основные переходы доступны непосредственно
через кнопки интерфейса.

## Источник истины

Для этой функции документы в данной папке имеют приоритет над текущими
baseline-требованиями в `docs/product/`. После реализации соответствующие
общие продуктовые документы необходимо синхронизировать по правилам из
[handoff](implementation-handoff.md).

## Связанное расширение

Карточка активной тренировки, просмотр snapshot-состава, точка продолжения и
завершение без сохранения описаны в пакете
[discard_active_workout](../discard_active_workout/README.md).

Целевой сценарий следующей итерации с обязательной проверкой состава перед
созданием сессии описан в
[home_analytics_and_workout_preview](../home_analytics_and_workout_preview/README.md).
Он переопределяет мгновенный старт по карточке и критерий «ровно два нажатия»,
сохраняя этот пакет как описание текущей локальной реализации.
