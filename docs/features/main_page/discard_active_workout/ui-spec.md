# UI-спецификация

Фича-пакет: `discard_active_workout`

Визуальный источник: [target/prototype.html](target/prototype.html).

## Карточка активной тренировки

Карточка располагается в существующей закреплённой зоне над primary CTA.
Высота зоны увеличивается только на необходимый контекст и не перекрывает
прокручиваемый контент.

Состав карточки:

1. eyebrow `Сейчас выполняется`;
2. название snapshot, максимум две строки;
3. resume-строка, максимум две строки;
4. увеличенный chevron `›`, выровненный по вертикальному центру справа от
   содержимого карточки.

Общий прогресс `X из Y упражнений` на компактной карточке не показывается. Он
доступен в заголовке sheet состава.

Вся карточка нажимаема. Видимая подпись `Посмотреть состав` не показывается.
Доступное имя карточки:
`Посмотреть состав активной тренировки <название>`. Вложенные действия
продолжения и отказа не должны вызывать открытие sheet из-за bubbling.

Primary CTA сохраняет существующий lime-стиль. `Завершить без сохранения`
остаётся текстовой tertiary-кнопкой; красная заливка появляется только в
подтверждении.

## Bottom sheet состава

На mobile sheet занимает до 85% доступной высоты и прокручивает только список.
Заголовок и нижняя зона действий остаются видимыми. На desktop используется
центральный modal шириной до 430 px.

### Заголовок

- drag handle;
- eyebrow `Активная тренировка`;
- название snapshot;
- сводка `Выполнено X из Y упражнений`;
- кнопка закрытия с доступным именем `Закрыть состав`.

### Список

Строка имеет:

- порядковый номер или `✓`;
- существующую иконку упражнения;
- название;
- вторичный текст состояния;
- без chevron для будущих упражнений.

Current-строка использует `--lime` как мягкий фон/рамку. Completed-строки
сохраняют читаемость, но имеют менее контрастный вторичный текст. Upcoming
остаются нейтральными.

### Нижняя зона

- primary: `Продолжить: подход N`;
- tertiary: `Завершить без сохранения`.

Если `resume = null`, primary меняется на существующее действие завершения с
сохранением; destructive-действие остаётся отдельным.

## Подтверждение отказа

Используется спецификация из `ux.md`. При входе из состава новый overlay заменяет
sheet состава. При отмене состав восстанавливается без повторной загрузки.

## Адаптивность

- При ширине до 390 px метаданные переносятся, но не скрываются.
- При высоте менее 700 px список sheet становится прокручиваемым раньше
  заголовка и действий.
- Touch target — не менее 44×44 px.
- Длинное название упражнения не сдвигает маркер состояния за границы.
