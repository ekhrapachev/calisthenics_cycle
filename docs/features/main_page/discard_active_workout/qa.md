# QA и приёмочное тестирование

Фича: `discard_active_workout`

## Критические проверки

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| Q-01 | Завершить пустую активную тренировку | Активная тренировка удалена, история и статистика не изменились |
| Q-02 | Завершить тренировку с подходами, таймером и заметками | Все данные активной тренировки исчезли, агрегаты не изменились |
| Q-03 | Отменить через безопасную кнопку | Прогресс полностью сохранён |
| Q-04 | Закрыть sheet/modal через Back, свайп или крестик | Прогресс полностью сохранён |
| Q-05 | Дважды быстро нажать destructive-кнопку | Выполнена одна логическая операция |
| Q-06 | Получить timeout/5xx/offline | Карточка и прогресс остаются, доступен retry |
| Q-07 | Повторить после временной ошибки | Операция завершается один раз |
| Q-08 | Начать новую при активной | После подтверждения автоматически продолжается выбранный старт |
| Q-09 | Отменить подтверждение при старте новой | Пользователь остаётся с текущей тренировкой |
| Q-10 | Завершить на другом устройстве во время открытого modal | После синхронизации нет ошибки и дубликатов |
| Q-11 | Перезапустить приложение во время запроса | После запуска показано фактическое состояние |
| Q-12 | Проверить историю, статистику, серию и прогресс плана | Ни один пользовательский агрегат не изменён |
| Q-13 | Открыть главную при resume на первом подходе первого упражнения | Карточка показывает правильное упражнение и `подход 1 из N` |
| Q-14 | Открыть состав после нескольких выполненных упражнений | Порядок соответствует snapshot, прошлые строки выполнены, текущая выделена |
| Q-15 | Продолжить из карточки и из sheet | Оба пути открывают одну пару `exerciseIndex + setNumber` |
| Q-16 | Изменить или удалить исходный набор после старта | Карточка и состав не меняются, используются данные snapshot |
| Q-17 | Закрыть sheet через Back, свайп, backdrop и кнопку | Данные не меняются, фокус возвращается на карточку |
| Q-18 | Увеличить системный шрифт при длинных названиях | Названия корректно переносятся/обрезаются, CTA и текущая позиция доступны |
| Q-19 | Открыть состав без сети после успешной загрузки главной | Используются уже загруженные `active.exercises`, новый запрос не выполняется |

## Дополнительные проверки

- Активная тренировка без сети доступна согласно текущей offline-политике.
- Истёкшая авторизация не приводит к локальной потере прогресса.
- После успеха back-navigation не возвращает удалённую тренировку.
- Deep link на удалённую активную тренировку ведёт в безопасное состояние.
- Несколько вкладок/окон корректно синхронизируют отсутствие активной тренировки.
- События аналитики отправляются один раз и содержат корректный `entry_point`.
- Тексты не обрезаются при увеличенном системном шрифте и в поддерживаемых
  локалях.
- Screen reader объявляет заголовок, последствия, действия, загрузку и ошибку.
- Порядок фокуса и возврат фокуса соответствуют UX-спецификации.
- Темы light/dark и состояния pressed/disabled/error визуально различимы.

## Регрессия

- Обычное продолжение активной тренировки.
- Восстановление первого незавершённого подхода после перезагрузки.
- Snapshot остаётся независимым от изменений исходного набора.
- Обычное успешное завершение с сохранением.
- Старт тренировки при отсутствии активной.
- Создание тренировки из шаблона/плана.
- Обновление истории и статистики после сохранённой тренировки.

## Definition of Done

- Все acceptance criteria из `requirements.md` автоматизированы на подходящем
  уровне или имеют зафиксированную причину ручной проверки.
- Q-01—Q-19 пройдены на целевых платформах.
- Если общая аналитика подключена, события проверены в тестовом окружении.
- Нет влияния на историю, статистику и прогресс плана.
- Тексты прошли продуктовую и локализационную проверку.
- Согласованы серверная семантика и поведение при конфликте между устройствами.
