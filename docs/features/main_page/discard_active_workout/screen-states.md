# Состояния зависимых экранов

Фича-пакет: `discard_active_workout`

## Главная

| ID | Условие | Карточка | Основное действие |
|---|---|---|---|
| H-01 | Активной сессии нет | Не показывается | `Начать тренировку` |
| H-02 | Active загружается | Skeleton в закреплённой зоне | Disabled |
| H-03 | Active + resume | Название, упражнение, подход и chevron | `Продолжить тренировку` |
| H-04 | Active + resume null | `Все подходы выполнены` | Безопасное завершение с сохранением |
| H-05 | Ошибка загрузки | Ошибка вместо частичной карточки | `Повторить` |
| H-06 | Выполняется discard | Карточка остаётся | Действия disabled |

## Bottom sheet состава

| ID | Условие | Поведение |
|---|---|---|
| D-01 | Открытие | Заголовок получает фокус, данные уже доступны |
| D-02 | Есть resume | Прошлые completed, текущая строка current, следующие upcoming |
| D-03 | Resume на первом упражнении | Нет completed-строк |
| D-04 | Resume на последнем упражнении | Нет upcoming-строк после current |
| D-05 | Resume null | Все строки completed, CTA ведёт к завершению с сохранением |
| D-06 | Сессия исчезла после синхронизации | Sheet закрывается, главная переходит в H-01 |
| D-07 | Длинные названия | До двух строк; метаданные и CTA остаются видимыми |

## Строка упражнения

| Состояние | Маркер | Текст |
|---|---|---|
| Completed | `✓` | `Выполнено` |
| Current | Lime-рамка/фон | `Продолжим отсюда · подход N из M` |
| Upcoming | Порядковый номер | `M × target unit` |

Цвет не является единственным различием: у каждого состояния есть текст и
маркер.

## Overlay-переходы

- Состав и подтверждение отказа не показываются одновременно.
- При переходе `состав → подтверждение` сохранить источник входа.
- Отмена подтверждения возвращает в исходный контекст.
- Escape закрывает только верхний overlay и никогда не подтверждает отказ.
