# Тексты интерфейса

Фича: `discard_active_workout`

## Основной набор

| Место | Текст |
|---|---|
| Действие на карточке | `Завершить` |
| Заголовок подтверждения | `Завершить тренировку?` |
| Описание | `Текущий прогресс не сохранится в истории и статистике. Это действие нельзя отменить.` |
| Destructive-кнопка | `Завершить без сохранения` |
| Безопасная кнопка | `Продолжить тренировку` |
| Toast после прямого завершения | `Тренировка завершена без сохранения` |
| Ошибка | `Не удалось завершить тренировку. Проверьте соединение и попробуйте снова.` |
| Повтор действия | `Попробовать снова` |

## Карточка и состав активной тренировки

| Место | Текст |
|---|---|
| Eyebrow карточки | `Сейчас выполняется` |
| Точка продолжения | `Продолжим: {exercise} · подход {current} из {total}` |
| Доступное имя карточки | `Посмотреть состав активной тренировки {routineName}` |
| Видимый маркер перехода | `›` |
| Заголовок sheet | `{routineName}` |
| Сводка | `Выполнено {completed} из {total} упражнений` |
| Текущая строка | `Продолжим отсюда · подход {current} из {total}` |
| Выполненная строка | `Выполнено` |
| Будущая строка | `{sets} × {target} {unit}` |
| CTA sheet | `Продолжить: подход {current}` |
| Ошибка состава | `Не удалось показать состав тренировки` |

Если название snapshot отсутствует, использовать `Активная тренировка`. Если
название текущего упражнения отсутствует, использовать `Следующий подход`, не
показывая пустые разделители.

## Вариант для контекста старта новой тренировки

| Место | Текст |
|---|---|
| Заголовок | `Завершить текущую тренировку?` |
| Описание | `Чтобы начать новую, завершите текущую. Её прогресс не сохранится в истории и статистике.` |
| Destructive-кнопка | `Завершить и начать новую` |
| Безопасная кнопка | `Вернуться к текущей` |

Контекстный вариант предпочтительнее, если система гарантированно знает, какую
новую тренировку выбрал пользователь. Он точнее обещает следующий шаг.

## Редакционные правила

- Не использовать `Сбросить`: слово не объясняет судьбу данных.
- Не использовать `Удалить тренировку`: пользователь удаляет незавершённый
  прогресс, а не шаблон или тренировку из плана.
- Не использовать двойное отрицание.
- Всегда прямо говорить, что прогресс не попадёт в историю и статистику.
