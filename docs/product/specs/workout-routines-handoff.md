# Пользовательские наборы тренировок

Статус: **ARCHIVE / предыдущая итерация**

Этот handoff зафиксировал переход от стандартного `PUSH / PULL` к
пользовательским наборам и больше не является источником поведения главной.
Предыдущая концепция с карточками наборов на главной заменена быстрым запуском.

Актуальные источники:

- [бизнес-требования](business-requirements.md);
- [пользовательские сценарии](user-scenarios.md);
- [feature-пакет новой главной](../../features/main_page/README.md);
- [основной кликабельный прототип](../prototypes/current.html).

Сохраняющиеся решения этой итерации:

- набор остаётся редактируемым шаблоном тренировки;
- экран «Мои тренировки» содержит просмотр, создание и переход в детали;
- детали набора поддерживают прогрессии, редактирование, удаление и запуск;
- начатая session использует неизменяемый snapshot и не зависит от последующего
  изменения или удаления набора.

Заменённые решения:

- карточки наборов, «Все» и «Новый набор» удалены с главной;
- создание доступно только через экран «Мои тренировки»;
- запуск с главной выполняется через bottom sheet за два нажатия;
- активная session продолжается с закреплённого CTA за одно нажатие.

Исторические визуальные материалы сохранены в `docs/product/mockups/current/` и
`docs/features/main_page/current/` только для сравнения.
