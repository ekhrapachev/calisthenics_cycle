# Прототипы Forma

Основной эталонный прототип локально реализованной версии:

- [Кликабельный HTML-прототип](current.html)
- [Feature-пакет быстрого запуска](../../features/main_page/quick_start_workout/README.md)
- [Feature-пакет прямой навигации](../../features/main_page/direct_home_navigation/README.md)
- [Предыдущий статичный референс главной](../mockups/current/home.png)

HTML-прототип открывается напрямую и покрывает:

- авторизацию;
- главную без активной тренировки;
- bottom sheet выбора набора и прямой запуск;
- главную с активной тренировкой и продолжение;
- управление тренировками через панель и плашку «Конструктор тренировок»;
- просмотр, создание, редактирование и удаление набора;
- выполнение подхода, отдых, историю, результат и профиль.

Для новой главной он фиксирует:

- отсутствие блока «Мои тренировки», «Все» и «Новый набор»;
- закреплённую кнопку «Начать тренировку» или «Продолжить тренировку»;
- сохранённое название active session над CTA;
- запуск карточкой непосредственно из панели;
- прямой переход в историю через всю карточку счётчика;
- прямой переход в конструктор через отдельную плашку;
- прямой переход в профиль через иконку справа сверху;
- отсутствие overflow-меню главной.

Числовые значения статистики, прогресса и цикла иллюстративны. Технические
состояния загрузки, ошибок и конкурентных запросов полностью определены
[требованиями feature-пакета](../../features/main_page/quick_start_workout/requirements.md) и
реализованы в приложении; прототип служит визуальным и навигационным референсом.
Изменения прямой навигации определены
[отдельным feature-пакетом](../../features/main_page/direct_home_navigation/requirements.md).

Предыдущая версия до редизайна остаётся в
[`docs/features/main_page/quick_start_workout/current/prototype.html`](../../features/main_page/quick_start_workout/current/prototype.html).
Исходный ранний PUSH/PULL-прототип сохранён в
[legacy-push-pull.html](legacy-push-pull.html).
