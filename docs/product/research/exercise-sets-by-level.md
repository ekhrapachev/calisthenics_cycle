# Наборы упражнений Push / Pull по уровням L0–L8

Версия: 1.0  
Назначение: источник упражнений для конструктора тренировочных наборов  
Основные цели: HSPU в Push, выход силой и фронтальный вис в Pull

## Общие правила

- Уровень выбирается по большинству доступных упражнений, а не по одному сильному элементу.
- Если последнее упражнение прогрессии пока недоступно, используется его облегчённый вариант.
- В начале тренировки выполняются технические и целевые движения.
- В каждом дне присутствует кор.
- Ноги представлены минимально:
  - Push — приседательное движение;
  - Pull — ягодицы и задняя поверхность бедра.
- Разминка плеч, локтей, запястий и лопаток подразумевается перед каждой тренировкой.
